# ✋ Yapay Zeka Destekli İşaret Dili Tanıma ve Metin Dönüştürme Sistemi

Bu proje, yapay zeka ve bilgisayarlı görü tekniklerini kullanarak işaret dili harflerini algılayan, algılanan harflerden cümleler oluşturan ve oluşturulan metni sesli konuşmaya dönüştüren interaktif bir web uygulamasıdır.

## 🚀 Özellikler
- **Yapay Zeka Destekli Harf Tespiti:** Görsel yükleme veya canlı kamera akışından harf algılama.
- **İnteraktif Harf Matrisi:** Manuel harf ve boşluk ekleme/silme paneli.
- **Görsel İşaret Akışı:** Yazılan cümlenin işaret dili alfabesindeki karşılıklarını görsel olarak sıralama.
